# GenesisWorld 开发路线

## Week 1: Project Initialization

- 初始化 Unity 2022 LTS + URP 工程
- 建立模块化目录与 GitHub 规范
- 完成架构、配置和开发日志文档

## Week 2–3: Procedural Environment Generation

- 建立可复现的随机种子系统
- 实现 Low-poly 环境布局与内容生成
- 补充算法说明与基础测试

## Week 4: Shader and Rendering Effects

- 使用 Shader Graph 构建风格化渲染效果
- 完善光照、后处理与性能分级

## Week 5–6: AI NPC Interaction

- 建立 NPC 领域模型与交互流程
- 抽象 AI 服务接口并实现安全的请求调度
- 支持离线模拟与异常降级

## Week 7: AIGC Asset Generation

- 定义 AIGC 辅助资产生产与审核流程
- 完成纹理、模型等资产的 Unity 导入规范

## Week 8: Optimization and Release

- 性能分析与跨质量等级优化
- 完善测试、文档、许可证和发布说明
- 发布可演示版本

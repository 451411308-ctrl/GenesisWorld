# GenesisWorld Roadmap / GenesisWorld 开发路线

## Phase 1 — Core Framework / 第一阶段：核心框架

**Status / 状态：Completed / 已完成**

**English**

- Initialize the Unity 2022 LTS + URP project.
- Establish the modular directory structure and GitHub conventions.
- Implement the CharacterController-based player system.
- Implement the third-person camera system.
- Publish the `v0.1.0` Week 1 milestone.

**中文**

- 初始化 Unity 2022 LTS + URP 工程。
- 建立模块化目录结构与 GitHub 规范。
- 实现基于 CharacterController 的玩家系统。
- 实现第三人称摄像机系统。
- 发布 `v0.1.0` 第一周里程碑。

## Phase 2 — Procedural World / 第二阶段：程序化世界

**Status / 状态：Planned / 计划中**

**English**

- Define reproducible random seeds and generation parameters.
- Generate basic terrain or modular low-poly environment layouts.
- Document generation algorithms and add focused tests.

**中文**

- 定义可复现随机种子与生成参数。
- 生成基础地形或模块化 Low-poly 环境布局。
- 记录生成算法并添加针对性测试。

## Phase 3 — Rendering / 第三阶段：图形渲染

**Status / 状态：Planned / 计划中**

**English**

- Build stylized rendering effects with Shader Graph or custom Shader code.
- Refine lighting, post-processing, and quality tiers.
- Profile rendering performance on target platforms.

**中文**

- 使用 Shader Graph 或自定义 Shader 构建风格化渲染效果。
- 完善光照、后处理与画质分级。
- 面向目标平台分析渲染性能。

## Phase 4 — AI Interaction / 第四阶段：AI 交互

**Status / 状态：Planned / 计划中**

**English**

- Define the NPC domain model and interaction flow.
- Introduce AI service abstractions and safe request scheduling.
- Support offline simulation, error handling, and service fallback.

**中文**

- 定义 NPC 领域模型与交互流程。
- 引入 AI 服务抽象与安全请求调度。
- 支持离线模拟、异常处理和服务降级。

## Phase 5 — AIGC Integration / 第五阶段：AIGC 集成

**Status / 状态：Planned / 计划中**

**English**

- Define an AIGC-assisted asset workflow and review process.
- Establish Unity import standards for generated textures and model drafts.
- Optimize approved assets for runtime use and document provenance.

**中文**

- 定义 AIGC 辅助资产工作流与审核流程。
- 建立生成纹理和模型草案的 Unity 导入规范。
- 优化审核通过的运行时资产，并记录资产来源。
